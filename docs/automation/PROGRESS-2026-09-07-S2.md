# S2 — CLI/operator surface

_Date: 2026-09-07. Scope authority: `docs/product/V01_SCOPE.md`._

## Implemented

- Added supported `ronin serve` composition over the existing `RoninHTTPServer`, `DurableExecutionService`, and SQLite store.
- Added supported `ronin worker` composition over the existing `LocalWorkerRuntime`; Docker remains behind the existing runner/kernel execution boundary.
- Added HTTP-backed `ronin submit`, `status`, `logs`, `jobs`, and `cancel` commands.
- Data-bearing commands support machine-readable `--json` output.
- `status --wait` uses bounded exponential polling and `logs --follow` polls the existing bounded Run-global event contract.
- Network commands use the existing `/v1/jobs` semantics and do not introduce new lifecycle, storage, runner, provider, engine, or cloud semantics.
- Expected CLI/control-plane failures return exit code 2 without a raw traceback; `KeyboardInterrupt` maps to 130 at the CLI boundary.

## Qualification added

The integration and frozen-journey qualification run the CLI against the real HTTP server and SQLite store, then prove:

- submit returns a queued durable job;
- status observes a terminal `succeeded` job;
- logs are dense and contiguous across two Attempts and preserve `attempt_id` plus attempt-local sequence provenance;
- replaying the same idempotency key after terminal success returns the same job and the same durable Run with no second job;
- the published `pyronin` client observes the same terminal state and replay identity over the same HTTP contract;
- `cancel` exposes the already-landed durable cancellation backend, without claiming container-cleanup acceptance.

## Planning consequence

The explicit corrected build plan supplied after the prior repository planning snapshot selected S2 before storage cleanup because the HTTP surface already existed. With S2 implemented, the next coherent Builder slice is the structural SQLite collapse: move final keyset/dense SQL into canonical `sqlite.py`, remove shadowed store classes, compose fencing without duplicate behavior, remove the per-file `sqlite.py` coverage exemption, and prove the canonical file at the normal threshold. Do not combine that storage slice with S2.
