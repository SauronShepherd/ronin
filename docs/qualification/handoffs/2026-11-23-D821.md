# Handoff D821 — recovery del scheduler PostgreSQL

D821 es PASS sobre `b5a007972f9ae73531f2f7692892e6e4ff6080b3`. El diagnóstico
filtrado contra PostgreSQL 16.4 aislado ejecutó `2/2` casos, sin skips ni
fallos, en 5,54 s.

La evidencia actual cubre dos propiedades: reacquisition después de lease
expirado sin disparo duplicado y replay del job después de crash del proceso
sin job duplicado. El runner reportó worktree limpio y cleanup PASS; PostgreSQL,
volumen y red temporales fueron eliminados.

Es evidencia bounded y filtrada, no la suite PostgreSQL completa, HA,
operación indefinida ni cierre de P11/release. No se reatribuye D100-D820.
P11 permanece `in_progress`, P13 `blocked` y release `NO-GO`.
