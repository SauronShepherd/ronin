# Handoff D501 — bulk replay PostgreSQL validado

D501 pasa el escenario live de 1.000 registros con bulk PostgreSQL habilitado:
`1/1`, 12/12 API OK y replay tras reset incluido. La corrección aplica el
fallback del bridge histórico, que compara el contenido estable del evento y
no `received_at`.

D502 conserva una limitación de escala: 10.000 registros aún excede el
timeout fijo de Playwright. P11 permanece `in_progress`, P13 `blocked` y
release `NO-GO`.
