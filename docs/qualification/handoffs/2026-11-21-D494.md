# Handoff D494 — frontera de ingestión bulk de eventos

D494 creó y verificó la frontera explícita `event_batch_ingestor` entre el
runtime y el scheduler sobre `8d4eab45ba9effbfca56f7cb308c10b6bc37a485`.
Construye todos los `SchedulerEventRecord` del micro-lote y permite que un
store implemente persistencia bulk; los stores actuales sin API bulk conservan
el fallback uno-a-uno. Pasaron 26 pruebas enfocadas, compileall y Ruff.

No se reclama todavía mejora live: el siguiente agente debe implementar el
`executemany` PostgreSQL sobre esta frontera, incluyendo replay conflictivo,
snapshot de triggers y entregas deterministas, y luego repetir la medición de
1.000 y 10.000 registros.
