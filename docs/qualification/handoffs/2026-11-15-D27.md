## Carencia productiva y corrección

La auditoría encontró que la composición local ya conectaba el plugin ML con
SQLite para Labs, metadatos, ejecuciones durables y artefactos, pero las
pruebas de composición sólo demostraban el wiring y no atravesaban la
superficie HTTP completa.

El commit `f685a54b` añade una regresión real sin mocks que crea un dataset y
revisión de catálogo, publica un Lab `ronin.ml-lab/v1` con el backend
`local.sklearn`, ejecuta quality, envía un entrenamiento durable de árbol de
decisión, espera el estado terminal, registra el modelo, verifica el digest de
artefacto, lee la tarjeta y un chunk del artefacto, predice, rechaza un
workspace desconocido y vuelve a leer tarjeta/predicción tras reiniciar toda la
composición.

La prueba observó el formato real del runtime (`sha256:<64 hex>`) y normalizó
el prefijo antes de comparar con el registro, sin fabricar un digest. El
dataset, el digest del Lab, el artefacto y la predicción determinista se
recuperan desde el mismo SQLite/ArtifactStore después del reinicio.
