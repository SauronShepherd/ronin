# Handoff D1157 — Helm PostgreSQL backend wiring — 23 noviembre 2026

D1157 introduce una frontera de producción exacta sobre `main`:
`6eab483e04b0bcd31d2f37e7475c6a7dad30196d`. El chart Helm conserva SQLite como
valor por defecto, pero ahora permite seleccionar explícitamente
`server.storageBackend: postgres`.

## Cambio implementado

- `server.storageBackend` acepta `sqlite` o `postgres`.
- `server.postgresDsn` es obligatorio cuando se selecciona `postgres`.
- El DSN se escribe únicamente en el Secret (`postgres-dsn`) y el deployment
  lo consume mediante `secretKeyRef` como `RONIN_POSTGRES_DSN`.
- `RONIN_STORAGE_BACKEND` siempre refleja el selector explícito.
- El chart no despliega PostgreSQL: requiere un servicio externo alcanzable.
