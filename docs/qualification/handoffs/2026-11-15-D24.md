## Carencias productivas y correcciones

La auditoría de D24 encontró que las rutas HTTP, la UI y el SDK ya tenían
operaciones de catálogo, ontología y graph, pero la CLI pública no ofrecía una
superficie equivalente para una jornada operable. Además, Graph Studio usaba
`default` en lugar del workspace activo y no permitía leer la ontología que
enlaza tipos graph con revisiones gobernadas del catálogo.

El commit `870484a5` añade al cliente de control-plane y a la CLI operaciones
bounded de lectura para assets, lineage, revisiones, ontologías y graph/RQL.
La jornada local real consume esas rutas con el SDK y la CLI; los datos se
persisten en SQLite, se aíslan con el mismo `graph_id` en dos workspaces y se
recuperan después de reiniciar la composición HTTP. También se añade el
rechazo de key JSON inválida y se conserva el 403 para un workspace no
autorizado.

Graph Studio hereda el contexto activo, vuelve a renderizarlo tras cambiar de
workspace y añade la lectura de esquema ontology. Las pruebas browser cubren
consulta, schema catalog-bound, objects, neighbors, cambio de contexto y
recuperación tras un error. Es evidencia de contrato UI; las respuestas
fulfill de Playwright no son certificación de proveedor.
