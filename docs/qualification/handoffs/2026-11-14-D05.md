## Cambio justificado

El servidor ya emite `matched_permissions` en la decisión de permisos del
proyecto, pero el SDK solo leía `matched_roles`; una respuesta válida podía
fallar cerrado en el cliente. Se alineó el parser del SDK con el campo
canónico, se conservó `matched_roles` como alias de compatibilidad y se añadió
cobertura para el round-trip de Bundle de proyecto.
